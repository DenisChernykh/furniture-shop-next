# Мебельный сайт на Next.js

Сайт мебельной компании с портфолио, описанием материалов, услуг и сотрудничества.

## Возможности

- Страницы компании, партнёрства и портфолио.
- Компонентные секции, слайдеры и анимация.
- Next.js, React, Prisma и работа с данными.

## Инженерные акценты

- Разработка визуально насыщенного сайта на React.
- Серверный рендеринг и связь интерфейса с моделью данных.
- Переиспользуемые секции и адаптивные состояния.

## Стек

React, Next.js, TypeScript, Prisma, Tailwind CSS, Swiper.

## Навигация по коду

- [app/](app/) — приложение.
- [prisma/](prisma/) — схема данных и миграции.

## Разработка

```sh
pnpm install
pnpm dev
pnpm build
pnpm lint
```
